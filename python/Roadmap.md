# 🧭 Roadmap to Become a Data Scientist

## 🔹 PHASE 1: Setup + Python Mastery (Foundation for Everything)

### 🔧 Software Setup

- Install: Anaconda (Python + Jupyter), VS Code
- Setup virtual environments (conda, venv)

### 🐍 Python (Core Language)

**Topics to Learn:**

- Data types: int, float, str, list, tuple, dict, set
- Control structures: `if`, `for`, `while`, `try`, `functions`, `lambda`
- List comprehension
- File I/O: `open()`, read/write files
- OOP basics: class, inheritance, methods
- Modules: `os`, `math`, `random`, `re`

---

## 🔹 PHASE 2: Data Handling & Cleaning

### 📚 Library 1: NumPy

**Learn:**

- Arrays: `np.array`, shape, indexing, slicing
- Array operations, broadcasting, axis-wise operations
- Random: `np.random.normal`, `randint`
- Reshape, flatten, stack, concatenate
- `np.where`, `np.isnan`, `np.isnull`

### 📚 Library 2: Pandas

**Learn:**

- `pd.Series`, `pd.DataFrame`, import/export CSV, Excel, JSON
- Indexing: `loc`, `iloc`
- Filtering, sorting, renaming
- `groupby`, `pivot_table`, `merge`, `concat`, `join`
- Handling missing data: `isnull`, `fillna`, `dropna`
- Working with datetime: `pd.to_datetime`, filtering by date

---

## 🔹 PHASE 3: Data Visualization

### 📚 Library 3: Matplotlib

- Line plot, bar plot, scatter, pie chart
- Labels, legends, titles, figure size
- Save plots

### 📚 Library 4: Seaborn

- Heatmap, boxplot, violin plot, pairplot
- `sns.histplot`, `sns.countplot`, `sns.barplot`
- Correlation visualization: `sns.heatmap(data.corr())`

### 📚 Library 5: Plotly / Altair (Advanced Optional)

- Interactive graphs and dashboards (Plotly Dash)

---

## 🔹 PHASE 4: Statistics + EDA

### 🧠 Core Concepts

- Descriptive stats: mean, median, mode, std, variance
- Probability: independent, conditional
- Distributions: normal, binomial, Poisson
- Central Limit Theorem
- Hypothesis Testing: p-value, z/t-tests, chi-square
- Correlation vs Causation
- Confidence intervals

**Libraries:** `scipy.stats`, `statsmodels`

---

## 🔹 PHASE 5: Machine Learning

### 📚 Library 6: Scikit-Learn (🔥 CORE)

#### Pipeline:

- Import + Split data: `train_test_split()`
- Choose algorithm: Classification / Regression
- Fit + Predict: `model.fit(X_train, y_train)`
- Evaluate: Accuracy, F1, ROC, RMSE, R²
- Tune: `GridSearchCV`, `RandomizedSearchCV`
- Scale: `StandardScaler`, `MinMaxScaler`

### ✳️ Algorithms to Learn:

**Classification**: Logistic Regression, KNN, SVM, Decision Trees, Random Forest, Naive Bayes

**Regression**: Linear, Ridge, Lasso, Polynomial Regression

**Clustering**: KMeans, DBSCAN, Hierarchical

**Dimensionality Reduction**: PCA, t-SNE
